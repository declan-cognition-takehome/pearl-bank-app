# @pearl/kyc-flow

Owned by **Digital Onboarding**.

Three-step know-your-customer flow (identity, address, review/consent) served at `/onboarding`.
Depends on `@pearl/shared-design-system` (page header, cards, buttons, status chip) and
`@pearl/shared-auth` (marks the session KYC-complete on submit).

```bash
npm run test:kyc-flow
npm run lint:kyc-flow
```
